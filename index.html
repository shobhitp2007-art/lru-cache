Data Structures Used

The UI is a visualization layer; the core project is the data structure implementation underneath it.

1. Hash Map
O(1) LOOKUP

Stores key → node references so a cache item can be found quickly.

A → Node A
B → Node B
C → Node C
2. Doubly Linked List
O(1) MOVE

Maintains usage order. Head is MRU and Tail is LRU.

HEAD ⇄ A ⇄ C ⇄ B ⇄ TAIL
3. LRU Policy
EVICT TAIL

When the cache is full, the least recently used item is removed first.

PUT(D) → remove LRU → insert D at HEAD

LRU Operation Logic

GET

Find key → move node to front → count hit/miss.

PUT

Update or insert → move to front → evict tail if full.

DELETE

Remove node from list and delete its map entry.

RESET

Clear the current cache state and statistics.
